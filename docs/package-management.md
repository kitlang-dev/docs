# Package Management

So far:

- Kit's compiler had YAML parsing builtin
- One of [Ben Morris](https://github.com/bendmorris)' Kit projects contain a [`kit.yaml`](https://github.com/bendmorris/krit-kit/blob/master/kit.yaml).
- There was at some point a [Kitten](https://github.com/AlexPoulsen/Kitten) package manager which would manage these files.

A planned step is to add a package manager to kitlang-rs which handles both of these use cases at once, while keeping compatibility with the existing ecosystem.
